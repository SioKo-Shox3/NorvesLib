# Rendering3DTest の既定の視点 overview から、一定の速さで右へ振り、エポックの直後と決めたフレーム数の後を撮る
# （回帰の撮影 Scripts/Terrain/CaptureRegression.ps1 -Motion。--scene=rendering3dtest --camera-script=Scripts/CameraScripts/rendering3dtest-pan.txt）。
# 書式は Game/Input/CameraScript.h。1 フレームは 1/60 秒。マウスの 1px は 0.15° なので、mouse=1 は毎フレーム 0.15° 右へ回る。
# 台本を流すのは自由飛行カメラ（FreeCameraRig）のシーンだけで、Rendering3DTest の軌道カメラはまだ台本を受け取らない
# （受け取るまでは -Motion の撮影に motion-* の PNG が出ず、回帰の比較が撮影の欠けとして落とす）。
# 撮る名前（<視点>.<名前>.png）:
#   motion-<k>  振りの途中で、エポックから k フレーム後（k = 0・8・30）
#   static-30   振り終えて止め、落ち着いてからエポックを始め、30 フレーム後
