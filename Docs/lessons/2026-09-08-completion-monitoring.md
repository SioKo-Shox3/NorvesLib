# 継続作業の終了条件を実証拠で確認する

全工程の完了を求められた作業では、バックグラウンド起動の確認を作業の終了条件にしない。プロセスの生存、直近のログ、ファイル差分、テスト結果、コミットと進捗記録を照合し、工程完了まで監視を続ける。

進行中と報告する場合は、現在のタスクと最後に確認できた具体的な進捗を示す。未着手のまま残った進捗表を修正し、未検証の実装を完了と表現しない。goalの使用をユーザーが認めた場合は、全体の完了条件をgoalへ明示する。

完了には必要な検証・評価・コミットが揃っていることを要求する。ユーザーの承認が必要な箇所は実物と証跡まで準備して提示し、それ以外の作業を継続する。
