# R7 パストレーシングの高さ霧輸送

## 入力と積分

PTはFramePacketのScene.VolumetricFogをR3と同じ正規化関数へ通し、密度・基準高さ・高さ減衰率をレイ生成シェーダーへ渡す。Henyey–Greenstein位相関数の異方性0.76はラスタ霧と内部定数を共有する。方向光はスナップショットから選び、遮蔽は霧中の24個の中点からのRT可視性レイで評価する。

交差までの各有限区間で、解析Beer–Lambert透過率によって表面寄与を減衰させる。霧色は有効なR2空放射輝度を優先し、空が無効または欠落した場合はSceneの霧色を使う。霧が無効なら区間寄与は恒等である。空への不交差レイはラスタと同じく霧を合成せず、空無効時は既存のPT環境光へ戻る。

## ラスタとの方式差

ラスタは深度のある一次レイに霧を合成し、方向光散乱には有効なCSMと対応するLightIdを要求する。PTは二次交差区間にも霧を適用し、CSMがなくても有効な方向光をRT可視性で評価する。CSM不在時や間接光のある画素では、同じ霧パラメータでも結果が異なる。

PTは有効なCSMのLightIdに一致する方向光を優先し、該当光がなければスナップショットを走査して最後の有効な方向光を選ぶ。複数の方向光があるシーンでは、ラスタと選択が異なる可能性がある。
