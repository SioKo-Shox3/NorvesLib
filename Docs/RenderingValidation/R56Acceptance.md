# R56 空の遮蔽の受入れ

判定日: 2026-11-12。空の遮蔽による鏡面反射と、樹冠の下から開けた場所までの遮蔽を記録する。樹冠の場面の結果は `RenderingSkyOcclusionCanopyVulkanTest` による。

## 1. 鏡面の遮り

`Assets/Shaders/Common/SkyOcclusion.glsl` の `EvaluateSkySpecularOcclusionCone` は、L1 から求めた曲げた法線を軸とする見える円錐と GGX ローブの交差を求める。円錐の半角 α は `cosα = sqrt(1 − V(曲げた法線))`、ローブは 13 層を Smith の `G1` で重み付けして平均する。計算式と層数は CPU の正解 `Library/Core/Private/Rendering/SkyOcclusionReference.cpp` の `EvaluateSkySpecularOcclusionCone` と同じである。

遮蔽物のない空（円錐の軸 +Y、可視率 1）との交差を `S_open`、遮蔽物を考えた交差を `S_occ` とすると、円錐から求める照明への係数は `clamp(1 − SpecularStrength · max(0, S_open − S_occ), 0, 1)`。開けた空から失った分だけを引くので、地平の下から来る地面の映り込みまで空の遮蔽として暗くしない。

滑らかな面では `EvaluateSkySpecularTransmittance` も使う。反射方向を `R`、面の位置を `P` とし、`R.y > 0` のとき、反射方向の距離 `t` を最初の区間 `[0, 0.5 m]` から終端を 1.4 倍ずつ伸ばし、最大 28 歩、`MaxHorizonMeters` まで辿る。最大距離は `skyOcclusionInfo.w` に float のビット列で渡す。各区間の中点で補助マップの `G`、`U−G`、`T−G`、`κ` を双線形補間し、光線の高さ区間 `[P.y + t_start·R.y, P.y + t_end·R.y]` と樹冠層 `[U, T]` の重なりを `overlap` とする。`σ = −ln(1−κ) / max(T−U, 0.5)`、`τ += σ·overlap / R.y`、透過率は `exp(−τ)`。重なる層の `κ ≥ 0.9999` は不透明とする。GPU は `τ > 9.22` で積算を打ち切る。地面との交差はここでは数えず、地面と地平の遮りは円錐に任せる。CPU の同名関数も同じ積算式で、無限平板の閉形式を `SkyOcclusionHorizonReferenceTest` が確かめる。

`w = 1 − smoothstep(0.25, 0.75, roughness)` とし、最終係数は円錐の係数と `clamp(1 − SpecularStrength·w·(1 − 透過率), 0, 1)` の小さい方。粗さ 0.25 以下では透過率を全重みで使い、0.75 以上では辿らない。粗さ 1 の地面と岩も辿らない。

`lighting.frag` の RTGI がない経路では、この係数を `specularAO` に掛け、IBL・DDGI の鏡面、平らな環境光の鏡面と SSR に渡す反射率に使う。RTGI の鏡面が有効な経路では、`rtgiSkySpecularOcclusion` と係数の小さい方を採り、さらに既存の `specularAO` とも小さい方を使うことで、空の遮りを掛け合わせて二重に数えない。RTGI の命中面の放射輝度にはこの AO を掛けない。RTGI が利用可能で開発用の `--rtgi-specular=off` を指定した場合は、従来の `specularAO` だけで鏡面環境光を返し、SVM の係数は掛からない例外である。`forward_transparent.frag` の半透明 IBL の鏡面も同じ共通関数を `specularAO` に掛ける。空の遮蔽が無効・未公開、または検証表示 `debugViewMode` 246〜255 のとき、空の鏡面遮蔽係数は 1 となる。

円錐だけでは樹冠の下の球の比が 0.517956 で、上限 0.30 に届かなかった。球の位置の L1 は `(B0, Cx, Cy, Cz) ≈ (0.183, 0, 0.429, 0.118)`、曲げた法線は真上から約 20°、円錐の半角は約 49°。実際に開いた空は −z 方向の地平の帯（仰角 33° 未満）だけだが、1 つの円錐は真上の周りが見える形で近似する。このため真上から見た球の円板の約 48% の反射方向が円錐内に入り、遮られない。鏡球の比の比較は第 3 節に示す。

## 2. GTAO との二重計上

GTAO は画面の深度と法線から近くの面を見て、空の遮蔽は地面・Solid・樹冠の代理を格子へ写して空の方向の遮りを積分する。`SSAOPass.h` の `Radius` の既定は世界長 1.0 m、`MaxRadiusPixels` は 128 画素であり、通常の `SceneView.cpp` も半径 1.0 m を設定する。

空の遮蔽の CPU `SkyOcclusionReference.cpp` と GPU `SkyOcclusion/Integrate.comp` はともに、最初の区間を `[0, 0.5 m]` とし、以後の区間の終端を 1.4 倍ずつ伸ばす。両方とも、最初の区間では水平距離 0.25 m の中点で遮蔽物の格子を引き、樹冠層との重なりは区間の両端の高さで求める。受け手の高さの既定は地面から 0.25 m。要件の「積分は 0.5 m から始める」は最初の歩の長さとしては満たすが、最初の標本の距離は 0.5 m ではなく 0.25 m である。反射方向の透過率も `[0, 0.5 m]` の区間から辿る。空の遮蔽の積分は水平方向距離、反射方向の透過率は光線に沿う距離なので、GTAO の世界空間半径と同じ物差しではない。

**結論:** 空の遮蔽は水平距離およそ 0.25 m から遮蔽物を数えるため、GTAO の既定半径 1 m の内側、概ね 0.25〜1 m では、描画される面であり Solid などの代理にも入っている遮蔽物を二重に数えうる。この試験の樹冠は代理だけでメッシュを描かず GTAO に映らないため、樹冠について二重計上は起きない。描画された葉が GTAO の半径に入る場合は重なりうる。画面外や代理に含まれない遮蔽物では、片方にしか現れないこともある。

GTAO の半径を世界長 1〜2 m 以下に保つ要件に対し、既定値は 1 m だが、半径の上限は設定 API で強制されない。

**鏡面:** RTGI のない IBL・DDGI・平らな環境光の鏡面と SSR の反射率では、`specularAO` に空の鏡面遮蔽係数を掛ける。RTGI の経路では `rtgiSkySpecularOcclusion` と係数の小さい方を採り、さらに `specularAO` とも小さい方を使う。空の遮蔽が有効なときは、どちらも同じ `EvaluateSkySpecularOcclusion` で係数を求める。開発用の比較経路 `--rtgi-specular=off` は例外で、`EvaluateRTGIEnvironmentSpecular` の `ddgiInfo.z` の分岐が変更前の式を使う。

**拡散:** 要件の版 1 は IBL の経路を対象とする。RTGI・DDGI のない IBL の拡散には SVM の可視率を掛ける。実際の AO は材質 AO と SSAO を合わせた後の色別 `GTAOMultiBounce` であり、単純な SVM×生の SSAO とは限らず、遮蔽物からの拡散反射も別途加算する。DDGI・RTGI の拡散では遮蔽を光線やプローブが解くため、SVM の可視率を掛けない。IBL のない平らな環境光の拡散にも掛けない。

## 3. 樹冠の場面の試験

`RenderingValidationScene.cpp` の `ApplySkyOcclusionCanopyFixture` は、Y = −1 m に 64 m 四方の地面（拡散のみ、色 0.55）を置く。樹冠の代理は中心 `(−2, 3.5, 0)`・`(0, 3.5, 0)`・`(2, 3.5, 0)`、半寸法 `(4, 2, 4) m`、κ = 0.9 の楕円体 3 個で、底は地面から 2.5 m、頂は 6.5 m。樹冠のメッシュは描かず、描画された葉や影ではなく空の遮蔽だけを測る。岩は中心 `(8, 0, −7)`、半寸法 1 m の描画する箱で、Solid の代理にも登録する。鏡球は金属 1・粗さ 0.1・色 0.9、半径 0.6 m、中心は樹冠の下 `(0, −0.4, −2)` と開けた場所 `(17, −0.4, −2)`。

カメラは `(4.25, 24, 0.6)` から `(4.25, −1, 0)` を見て、露出は f/4・1/60 s・ISO 100。大気は無効のまま、`SetStaticEnvironmentUniformRadiance` で一様な静的環境の放射輝度を 200 とし、基本の方向光を消す。大気を有効にすると空の太陽による方向光が加わるため、この試験では方向光のない一様な環境を使う。空の遮蔽の窓の中心は `(4.25, 0)` に固定し、各段の判定には切り替え後の `settled_frames ≥ 32` を要する。

地面の樹冠下と開けた点はそれぞれ 5×5 画素の線形輝度平均。林縁は `(−8, −1, 1.5)` から `(−0.5, −1, 1.5)` まで 0.5 m 間隔の 16 点で、各点の 3×3 画素の線形輝度平均を測る。鏡球は投影円板の半径の 0.6 倍以内だけを平均する。中央側は空を映し、外側は地平以下を含む。一様環境では地平以下も同じ放射輝度なので、遮蔽の比較から外側を除く。

## 4. 残る限界

L1 と 1 つの円錐では、樹冠の下のように地平の帯だけが開いた空を表しきれない。滑らかな面は反射方向の透過率で補うが、中間の粗さ 0.25〜0.75 は重みを変えた透過率と円錐の小さい方を採る近似で、ローブの広がりは反射の 1 方向でしか調べない。透過率が数えるのは樹冠の層だけで、建物などの Solid は円錐が受け持つ。

滑らかな画素では、透過率の評価に最大 28 歩 × 各歩 4 回の補助マップ読みが増える。GPU 時間は測っていない。遮蔽物の表現は 2.5D のため、庇の下のように高さごとの空洞や上下に重なる複雑な形を表しきれない。パストレーサーの参照との比較はこの文書の範囲外。
