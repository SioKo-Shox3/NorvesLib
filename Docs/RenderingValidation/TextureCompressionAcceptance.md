# テクスチャ圧縮の画質と受入れ

`AssetCookBlockCompressSmoke` が CPU 上で圧縮・復号した画質の初回実測と、回帰検出のしきい値を記録する。実測は 2026-11-10 の Debug の詳細出力による。ロードマップの暫定値との比較には、変化のある CobbleStoneFloor の実画像を使う。

## 測り方

実画像は `Assets/Textures/Silver` と `Assets/Textures/CobbleStoneFloor` の 2 組。Silver は受入れ条件で指定された素材で、画像は `silver_albedo.png`・`silver_normal-ogl.png`・`silver_ao.png`・`silver_roughness.png`・`silver_metallic.png`。CobbleStoneFloor は `cobblestone_floor_09_diff_4k.png`・`cobblestone_floor_09_nor_gl_4k.png`・`cobblestone_floor_09_arm_4k.png` で、いずれも 4096×4096 の 16bit PNG を 8bit RGBA に復号して測る。

実画像の窓は中央ではない。各画像について、左上を 256 画素おきの格子に置いた 512×512 の窓から、R・G・B の分散の和が最大の窓を選ぶ。同値なら上から左の順で最初の窓を使う。Silver の AO・粗さ・メタリックの元画像が同じ寸法なら AO の窓を共有するが、今回の元画像は寸法が異なるため、それぞれの窓を選んでから ORM に詰める。

| ケース | 圧縮と測定 |
|---|---|
| `silver_albedo`・`cobblestone_albedo` | BC7 sRGB 相当の perceptual 設定で圧縮し、元と復号後の 8bit RGB の PSNR を測る。 |
| `silver_normal`・`cobblestone_normal` | BC5 の R・G を −1〜1 に写し、`z = sqrt(max(0, 1 − x² − y²))` で元と復号後の法線を組み、正規化して角度誤差の平均・最大を測る。元画像の B は角度の比較に使わない。 |
| `silver_orm`・`cobblestone_orm` | R=AO・G=粗さ・B=メタリックを BC7 linear で圧縮し、各チャンネルの最大絶対差を 8bit 値で測る。Silver は各元画像の R を詰め、CobbleStoneFloor は詰め済みの ARM を使う。 |
| `BC6H` | 64×64 の合成 HDR の RGB を符号なし BC6H で圧縮し、各チャンネルの `abs(log2(max(復号値, ε)) − log2(max(元値, ε)))` の平均・最大を測る。`ε = 1e-4`。 |
| `BC3` | 64×64 の合成 RGBA を圧縮し、RGBA 全チャンネルの PSNR を測る。 |
| `BC7`・`BC7_alpha`・`BC5`・`BC4`・`BC1` | 同じ 64×64 の合成画像を使う既存ケース。比較対象はそれぞれ RGB・RGBA・RG・R・RGB。 |

圧縮品質は `Normal`。PSNR の平均二乗誤差が 0 のとき、スモークは無限大の代わりに 99 dB を出力する。

BC6H の合成画像には値が大きく跳ねる区画（x=17〜42、y=21〜38）がある。この区画に一部でもかかる 4×4 ブロックは、区画の外側の画素も含めて `edge`、それ以外は `smooth` として RGB を別々に集計する。標本数は各チャンネルで `smooth` 3536、`edge` 560。

## ロードマップの暫定値との比較

| 項目 | 暫定値 | Silver 実測 / 比較 | CobbleStoneFloor 実測 / 判定 |
|---|---|---|---|
| albedo PSNR | 40 dB 以上 | 99.000000000 dB / 満たす | 46.018896691 dB / 満たす |
| 法線の平均角度誤差 | 1.0° 以下 | 0.000000000° / 満たす | 0.988492768° / 満たす |
| 法線の最大角度誤差 | 6.0° 以下 | 0.000000000° / 満たす | 21.730508650° / **満たさない** |
| ORM R の最大差 | 8/255 以下 | 0/255 / 満たす | 10/255 / **満たさない** |
| ORM G の最大差 | 8/255 以下 | 1/255 / 満たす | 13/255 / **満たさない** |
| ORM B の最大差 | 8/255 以下 | 0/255 / 満たす | 2/255 / 満たす |

Silver の数値は参考であり、前述の単色に近い素材から圧縮の画質を判断できない。CobbleStoneFloor では法線の最大値と ORM の R・G が暫定値を超えるため、**ロードマップの暫定値を満たさない**。スモークの合格は上の回帰検出用しきい値を通ったことを示す。

## 用途と形式

| 用途 | 既定 | 形式の指定 |
|---|---|---|
| `hdr` | BC6H linear（符号なし） | `--format rgba16f` で RGBA16F linear |
| `albedo` | BC7 sRGB | `--format bc3` で BC3 sRGB |
| `normal` | BC5 linear | — |
| `orm` | BC7 linear | `--format bc3` で BC3 linear |

BC6H の符号化は `Library/ThirdParty/DirectXTex/UPSTREAM.json` に固定された DirectXTex `may2026`、commit `4feb3e11a020f35b796fc769a74216a555d4f5ef` による。

この文書の画質は CPU の符号化・復号によるもので、GPU 上の標本値を測るものではない。GPU の BC6H・BC3 の標本は `RHIBlockCompressedTextureVulkanTest` が手組みの単色ブロックをアップロードして読み戻す形式の試験で確かめる。AssetCook が符号化したブロックの GPU 上での画質は、このスモークでは測っていない。
