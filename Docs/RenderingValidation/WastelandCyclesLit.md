# 実材質の地形をエンジンと Cycles で描き、照明を比べる

荒野の正解の絵（SCN-WLR-*）で、実際の地表の材質（SCN-WLR-MATERIAL-ALBEDO・NORMAL で照合した再現）の地形を、共通の照明
（一様な空と太陽）でエンジンと Blender の Cycles の両方で描き、露出前の HDR を領域ごとに比べた記録。手本の写真とも並べ、
写真との差は照明・天気・現像・写っている物の違い（条件の違い）と分けて書く。比べるだけで、エンジンの照明と材質は直していない。
判定日: 2026-10-19。ブランチ `feature/scene-launcher`。タスク SCN-WLR-CYCLES-LIT-A（ref_cliff_01・ref_far_01・ref_ground_01）・
SCN-WLR-CYCLES-LIT-B（ref_far_02・ref_cliff_02・ref_ground_02 と写真との比較）。

## 道具

| 何 | どこ | 何をするか |
|---|---|---|
| `Scripts/Terrain/BlenderReference.py --lit` | Blender 5.2.2 をヘッドレスで起動 | 視点ごとに 2 段で描く。1 段目は画素ごとの材質（`TerrainAlbedo.osl` のアルベド・法線・粗さ・材質の AO と深度）を `<撮影>/material/` に、2 段目はその材質を当たりに使う Cycles の照明つきの描画を `<撮影>/cycles/` に書く。視点を分けて描けるよう、同じ台本・値の表・撮影なら前の視点の記録を残して足す |
| `Scripts/Terrain/ReferenceCheck.py --lit` | | 撮影・材質・Cycles の入力と標本の位置を検査し、領域ごとの表 `lit_check.json`、比較画像 `lit_<視点>.png`（エンジン｜Cycles）、領域と比の画像 `lit_regions_<視点>.png`、写真｜エンジン｜Cycles の `lit_photo_<視点>.png` と一覧 `lit_photo_overview.png` を書く |

材質の再現と照合の基準は `WastelandMaterialAlbedo.md`・`WastelandMaterialNormal.md`、照明・Cycles の設定・領域・収束の定義は
`WastelandCyclesGray.md` と同じ（材質だけが灰色から実材質に変わる）。

## 条件

- エンジン: `CaptureScene.ps1 -Scene wasteland -Configuration RelWithDebInfo -Hdr -Aov -Views <6 視点>
  -GameArgs wasteland-common-light,wasteland-hide=all,wasteland-finest-lod`（地形だけ・共通の照明・最細の LOD）。6 視点とも
  撮った時点でジオメトリのページの進行中 0・追い出し 0、描くクラスタの溢れ 0。
- 太陽の向き（`Scripts/Terrain/CommonLight.json`。方位は東から南へ測る）: ref_far_01 高さ 58.5°・方位 154°、ref_far_02 45°・160°、
  ref_cliff_01 10°・172°、ref_cliff_02 24°・132°、ref_ground_01 51°・90°、ref_ground_02 38°・125°。空は全方向で同じ放射輝度
  （RGB 4000・5000・6500 cd/m²）、太陽は垂直な面で 100000 lx。大気・霞・雲は無い。
- Cycles: 地形はカメラから水平 4 km（影の届く範囲）の区画（下の収束の表）。当たりの材質は OSL（アルベド・法線・粗さ）。
  材質の AO は Cycles に渡さない（経路の追跡が遮蔽を幾何から解く）。
- 標本の位置: 画素ごとの材質の深度とエンジンの深度から求めたずれが 0.05 画素を超えた視点は、カメラをずらして描き直した
  （下の収束の表。残りのずれは 6 視点とも 0.02 画素以下）。Cycles の描画は材質と同じずらしで描く。
- 比較画像: エンジンの撮影の `hdr.json` の表示変換（SCN-WLR-DISPLAY-TRANSFORM の `DisplayTransform.py`。同じプリエクスポージャ・
  トーンマップ・グレーディング・ビネット）を両方に掛けた。Cycles の空（透明の背景）は共通の照明の一様な空の放射輝度で埋める。

## 差の大きい所の原因の見立て

撮影の Game のログは 6 視点とも `RT_SCENE instances=0` で、灰色の比較（`WastelandCyclesGray.md`）と同じくレイトレーシングの
シーンに地形が入っていない（RTGI は遮蔽も照り返しも無い空を返し、GTAO も重ねない）。

1. **材質の AO（日なたの地面の −18〜−30 % の主因）**: エンジンは材質の AO（ORM の値。日なたの地面で平均 0.62〜0.73）を直接光に
   0.3 の重みで、環境光にそのまま掛ける（`lighting.frag` の `directAO`・`ddgiAmbientAO`）。Cycles は材質の AO を使わない。
   同じ AO を Cycles の太陽の組・空の組へ掛けると、比は 0.71〜0.82 から 0.87〜0.98 に寄り、灰色の材質の比（ref_cliff_01 0.953・
   ref_far_01 0.975）と同じ大きさの残りになる。青ほど比が低い（0.60〜0.75）のは、青い空の光に AO がそのまま掛かるため。
   平らな砂地の AO が 0.6〜0.7 台と強いこと、直接光にも掛けることの両方が候補（AO の値の焼き方と掛け方は、ここでは確かめていない）。
2. **ref_cliff_02 の影の中の地面が明るい（2.22 倍）**: 右手前の台地の長い影がエンジンに落ちない。撮影のログでは、この視点だけ
   仮想の影の地図のページが 38（使った段は 1 つ、`VSM_PAGES ... levels_used=0x200`）と少なく、影の地図に当たらない標本の数
   （`VSM_LIGHTING_STATS fallback_samples`）が 1 回の描画あたり約 1210 万（ほかの 5 視点は 15 万〜390 万）。影の地図が手前の
   地面を覆っていない疑い（未確認）。灰色の比較で見た「落ちた影に太陽が漏れる」（ref_cliff_01）も同じ元の候補。
3. **ref_cliff_01 の影の崖が明るい（+77 %、未判定）**: 灰色の比較の +57 % と同じ元（空の遮蔽と照り返しが無い）。材質の AO を
   見込んでも 1.86 で、AO では説明できない。Cycles の影の崖の照り返しの割合が 29 % と大きく（赤い岩の照り返し）、色の比が赤 1.55・
   緑青 1.9 と分かれる（エンジンの環境光は青い空だけ）。ほかの 3 視点の影の崖は 0.875〜1.007 で平均は近いが、色は同じ向きに
   分かれる（赤 0.77〜0.82・青 0.91〜1.41）。比較画像で崖の陰が浅く黄色く見えるのはこの分。
4. **かすめる日差し（ref_cliff_02 の日なたの地面 0.705・遠景 0.764）**: 太陽の高さ 24° のこの視点は、AO の見込みとの比も
   0.874・0.929 と他より低い。灰色の比較の「遠くのかすめる日差しが暗い（n·l 0.1〜0.3 で 0.61）」と同じ向き。
5. **残り（AO の見込みとの比 0.91〜0.98）**: 灰色の比較と同じく、照り返しの欠け（日なたの崖の Cycles の間接光 5〜10 %）。
   ref_cliff_01 の日なたの崖は AO の見込みで 1.000 に揃う。遠景の赤の比が低い（0.80〜0.93）のは遠景の赤い崖の照り返しの欠けと見ている。

## 未判定と限界

- 未判定: ref_cliff_01 の影の中の地面・影の崖（2048 サンプルで収束しない）と遠景（画素なし）、ref_far_01 の影の中の地面・
  影の崖（画素なし）と日なたの崖（511 画素）、ref_far_02 の影の中の地面（48 画素）、ref_cliff_02 の日なたの崖（122 画素）、
  ref_ground_01 の影の中の地面（画素なし）と影の崖（39 画素）、ref_ground_02 の影の中の地面（1930 画素）。
- 「AO の見込み」は太陽の組の照り返しにも直接光の係数を掛ける近似で、合否には使わない。
- 写真との比較は表示の値で、写真の現像が分からないので合否に使わない。写真の枠は写真の構図に合わせた枠で、エンジン・Cycles の
  同じ枠には写真と違う物（植生の無い地面など）が入る。
- BC5・BC7 の圧縮と GPU の異方性の標本は、材質の照合（`WastelandMaterialAlbedo.md`・`WastelandMaterialNormal.md`）の範囲で
  再現している。Cycles はカメラから水平 4 km の外の区画を読まない（`WastelandCyclesGray.md` と同じ）。
- 比較画像の Cycles の空は一様な空で埋めており、エンジンの空（大気の散乱）とは違う。地形の部分だけを見る。

## 手順

```
# エンジン（照合の読む撮影。6 視点で約 9 分）
powershell -Command "& ./Scripts/CaptureScene.ps1 -Scene wasteland -OutDir .harness/runs/scene-capture/SCN-WLR-CYCLES-LIT `
  -Views ref_far_01,ref_far_02,ref_cliff_01,ref_cliff_02,ref_ground_01,ref_ground_02 -Configuration RelWithDebInfo -Build `
  -Width 1920 -Height 1080 -Hdr -Aov -LaunchPerView -GameArgs @('--wasteland-common-light','--wasteland-hide=all','--wasteland-finest-lod')"
# Blender（1 視点ずつ。材質と Cycles で 1 視点 10〜40 分。ずらしの要る視点は材質を 2 回描く）
python Scripts/Terrain/BlenderReference.py --lit --views ref_cliff_01 --camera-shift-hint 0.243,0.027 `
  --mesh .harness/runs/scene-capture/SCN-WLR-BLENDER-TERRAIN-mesh --capture .harness/runs/scene-capture/SCN-WLR-CYCLES-LIT
python Scripts/Terrain/BlenderReference.py --lit --views ref_far_02 `
  --mesh .harness/runs/scene-capture/SCN-WLR-BLENDER-TERRAIN-mesh --capture .harness/runs/scene-capture/SCN-WLR-CYCLES-LIT
#   （ref_far_01・ref_cliff_02・ref_ground_01・ref_ground_02 も同じ形で）
# 照合
python Scripts/Terrain/ReferenceCheck.py --lit --views ref_far_01,ref_far_02,ref_cliff_01,ref_cliff_02,ref_ground_01,ref_ground_02 `
  --capture .harness/runs/scene-capture/SCN-WLR-CYCLES-LIT --verify
```

約 35 GB 使うので、2 本を重ねて起動しない。
