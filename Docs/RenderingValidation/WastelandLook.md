# 荒野の写りの診断（写真ごとの固定の領域）

確認 2（SCN-WL-REVIEW-2）の差 3・6・7（地面と崖が写真より明るい・晴天の空が白い・遠景の霞が桃色）を、手本の写真と構図を合わせた
6 視点の撮影で、写真ごとに決めた同じ領域の値として比べる。値は診断のためのもので、**この記録では値を変えない**。

## 測り方

```
powershell -NoProfile -ExecutionPolicy Bypass -File Scripts/CaptureScene.ps1 -Scene wasteland -Configuration RelWithDebInfo -Build -RequireAssets -Width 1920 -Height 1080 -Hdr -Views ref_far_01,ref_far_02,ref_cliff_01,ref_cliff_02,ref_ground_01,ref_ground_02 -OutDir .harness/runs/scene-capture/SCN-WL-LOOK-MEASURE
python Scripts/Terrain/CompareReference.py --capture .harness/runs/scene-capture/SCN-WL-LOOK-MEASURE --look --verify
```

- 領域の注釈は `Scripts/Terrain/LookRegions.json`。写真ごとに 青空（雲を除く）・雲・近景の日なたの地面・崖・3 km より先の地形の帯 を
  多角形で置く。座標は 16:9 に合わせた絵（`CompareReference.py` の `fit_photo`）の割合で、写真と撮影の両方に同じ多角形を重ねる。
  構図が合っていない所（far_02・ground_01・ground_02 の遠景の帯）は `capture_polygon` で撮影の側だけ同じ物の写る所へ置き直した。
  写真に写っていない領域は `absent` に理由を書く（下の表の「この写真に無い」）。青空（雲を除く）は、写真と撮影の両方で雲の筋の無い所に置く
  （0.05 刻みの升ごとの B ÷ R と輝度のばらつきで、どちらにも雲の掛からない所を選んだ。cliff_01 は写真の空の大半に巻雲の筋があるので上端の右の
  切れ間、ground_02 は撮影の上の方の薄い雲の筋を避けた帯）。
- 集計は `Scripts/Terrain/LookMeasure.py`（`CompareReference.py --look` から呼ぶ）。写真と撮影の PNG は sRGB を線形に戻した表示の値、
  撮影の HDR（`<視点>.hdr.pfm`）はブルームと表示の変換の前の放射輝度（cd/m²）。Y = 0.2126R + 0.7152G + 0.0722B を平均の RGB から求め、
  色度は R ÷ G・B ÷ R。白飛びはどれかのチャンネルが 254 以上、黒つぶれはすべてのチャンネルが 4 以下（sRGB 8 bit）の画素の割合。
- 仰角と太陽からの角距離は撮影の視点のカメラ（`SceneCatalog.h` の Yaw・Pitch、`WastelandRoutine.cpp` の `kReferenceShots` の縦の画角と、
  写真の日時に合わせた太陽の高度・方位）から画素ごとに求め、写真の多角形と撮影の多角形で別々に書く。写真のカメラの向き・画角は記録が無いので、
  写真の側は撮影の視点のカメラで近似した値（表の ※）。構図を合わせた視点では両者はほぼ同じで、撮影の側だけ置き直した遠景の帯では違う
  （far_02 写真 0.4〜1.6°・撮影 1.4〜2.9°、ground_02 0.3〜0.9° と 0.2〜0.5°）。構図を合わせていない ground_01 は写真の水平線が撮影より下に
  写るので、写真の遠景の帯は近似では仰角 −3.0〜−1.1°・太陽から平均 107° と出るが、実際は水平線のすぐ上で、粗い近似として読む。画面の上端の仰角は ref_far_01 9.9°・ref_far_02 15.7°・ref_cliff_01 17.0°・
  ref_cliff_02 3.0°・ref_ground_01 19.1°・ref_ground_02 6.6°。
- 遠景の帯が 3 km より先かは、同じ視点の -Aov の撮影（`scene-capture/SCN-WLR-CYCLES-LIT` の `<視点>.aov.depth.pfm`）を
  `--look-depth` で渡して確かめた: 帯の画素の 3 km より先の割合は 5 視点とも 100 %（深度の中央値 far_01 4.5 km・far_02 5.1 km・
  cliff_02 5.3 km・ground_01 11.5 km・ground_02 3.4 km）、空の画素は 0 %。崖は far_01 4.1 km、ほかは 0.5〜2.5 km。
- 注釈を重ねた画像 `look_<写真>.png`（上: 写真、下: 撮影）を 6 枚とも開いて、領域が意図した物（青空は雲の無い所、崖は壁、地面は手前の地表、
  遠景の帯は遠い地形だけ）に乗っていることを確かめた。撮影の雲は写真の雲に合わせていないので、撮影の「雲」の領域は far_01・cliff_02 では
  雲の無い空、ground_01 では青空と雲の混じった所になる（写真の雲との比べは雲の明るさの比べにならない）。
- 撮影: HEAD 1bdfc466 の RelWithDebInfo（Game.exe 029d0d3d…）、6 視点とも白飛び・黒つぶれ 0。HDR は SCN-WL-LOOK-CAMERA が
  オフラインで表示の変換を選ぶのに使う。

## 見立て

差を (a) カメラの写り（露出・トーンカーブ・白飛び・ホワイトバランス・表示の変換）、(b) 物の明るさ（アルベド・植生の被覆）、
(c) 空と霞の入力（媒質・地表の反射の色・写真の天気）に分ける。

### 差 3: 地面と崖が写真より明るい

- 撮影の PNG の地面は写真の 1.7〜3.0 倍（cliff_01 だけ 1.06 倍）、崖は 1.7〜6.7 倍明るい。一方で雲の無い青空は 0.69〜1.35 倍
  （far_01 0.89 倍・cliff_01 0.69 倍・ground_02 1.35 倍）で、画面全体の露出のずれ（一律の倍率）では説明できない。地面 ÷ 青空は
  写真 0.18（far_01）・0.46（cliff_01）・0.53（ground_02）に対し撮影 0.52・0.69・0.63（HDR）で、撮影の地面は空に対して 1.2〜2.9 倍明るい
  （真昼の far_01 で最も大きい）。
- (a) 撮影の HDR → PNG で比はほとんど変わらない（地面 ÷ 青空 0.52 → 0.59、崖 ÷ 地面 1.02 → 1.14）。表示の変換（NeutralLinear・
  中立のグレーディング）は地面を持ち上げていない。写真の側は、空を肩で留めたまま地面が中間調の下に置かれている（far_01 の地面は
  sRGB で約 100）。カメラのトーンカーブと露出の取り方が地面を沈める分は (a) に入るが、写真の処理が分からないので量は決められない。
  白飛びは写真にだけあり（far_01 の遠景の帯 3.5 %・ground_01 の雲 2.8 %・ground_02 の地面 0.6 %）、撮影は全領域で 0 % — 撮影はカメラの肩を持たない。
- (b) 写真の地面の枠には低木と株の影が多く（far_01・far_02・ground_01 の写真は手前が一面の低木、撮影の低木は疎ら）、平均を下げている。
  崖 ÷ 地面は崖のある 5 写真のうち 4 つで撮影の方が大きい（far_02 0.92 → 1.60、cliff_01 1.13 → 1.67、cliff_02 0.91 → 1.27、ground_02 0.18 → 0.64）。
  地面と崖が同じ倍率で明るいのではなく崖の方が持ち上がっているので、崖のアルベドか、崖の面の遮蔽（小さな凹凸と庇の影。ユーザーの所見の
  「遮蔽による影の落ち方の質が低い」）が足りない見込みが高い。ground_02 の写真の崖は濃い赤褐色の層で 0.047 と暗く、撮影は 0.316 で
  写真の 6.7 倍明るい。
- まとめ: 差 3 の主因は (b)（植生の被覆・崖の明るさと遮蔽）で、(a)（写真の露出とトーンカーブ）が上乗せされている。
  SCN-WL-LOOK-CAMERA で (a) の分を表示の変換として選んだ後に、残りを (b) で詰める順がよい。

### 差 6: 晴天の空が白い

- 雲の無い青空は、写真と撮影の両方で雲の筋の無い所だけに置いた（cliff_01 の写真は空の大半に巻雲の筋があるので上端の右の切れ間、
  ground_02 は撮影の上の方の薄い雲の筋を避けて仰角 2.4〜4.3° の帯）。B ÷ R（HDR）は次のとおり:
  - far_01（仰角 9.4〜9.9°、太陽から 79°、太陽の高度 58.5°）: 写真 1.65・撮影 1.63 とほぼ同じ。
  - cliff_01（仰角 16.0〜16.9°、太陽から 127°、太陽の高度 10°）: 写真 5.67・撮影 2.90。撮影の空は写真の 0.69 倍の明るさ。
  - ground_02（仰角 2.4〜4.3°、太陽から 71°、太陽の高度 38°、快晴）: 写真 3.30・撮影 1.76。撮影の空は写真の 1.35 倍の明るさ。
  真昼の高い太陽で地平線から 10° の far_01 は合い、地平線に近い ground_02 と、低い太陽の反対側の cliff_01 で撮影の空の青みが写真の約半分に
  留まる。撮影の HDR と PNG で色度は同じ（ground_02 1.76 → 1.72、cliff_01 2.90 → 2.90）なので、白さは表示の変換ではなく HDR の空そのものにある。
- (a) ground_02（B ÷ R 3.30、R ÷ G 0.49）と cliff_01（5.67、0.41）の写真の空の青さは、彩度を強めた現像か偏光フィルタの見込みがあり、
  写真の処理の分を含む。far_01 の空は青みが合うので、空の色の作り方が全体に外れているのではない。
- (c) 地平線に近い空は撮影の方が明るく色が薄い（ground_02 の青空の Y は写真 0.505・撮影 0.682）。地平線の近くでエアロゾル（Mie）の散乱が
  Rayleigh に対して強いか、地表の反射の色（赤い地面）が多重散乱の空を暖色へ寄せている見込み。cliff_01 は太陽が低い（10°）ので、
  太陽の光が長い経路で赤くなる分と、オゾンの吸収（Chappuis 帯）が低い太陽の空を青くする分が効く条件で、撮影でどちらが足りないかは
  この記録の量だけでは分けられない。写真の天気は far_01・cliff_01・ground_02 が晴天なので、この 3 枚で比べる。
- まとめ: 差 6 は (c)（地平線に近い空と低い太陽の空の媒質・地表の反射）が主で、ground_02 と cliff_01 の写真の処理（(a)）が差を大きく見せている。

### 差 7: 遠景の霞が桃色

- 写真の遠景の帯は近景の地面より R ÷ G が 0.40〜1.39 下がり、B ÷ R が 0.25〜1.78 上がる（遠いほど青い）。撮影は R ÷ G が 0.07〜0.93
  下がり、B ÷ R が 0.13〜0.55 上がるだけで、遠景が地面の赤みを残したまま白く明るくなる（ground_01 の帯の Y は写真 0.142・撮影 0.561）。
  赤みが残ったまま白い光が足されるので、桃色に見える。HDR と PNG の差は 0〜0.04 で、表示の変換は霞の色を作っていない。
- (c) 写真の 6 枚のうち far_02・cliff_02・ground_01 は薄曇り・曇天で、遠景の青み（cliff_02 の帯の B ÷ R 2.17）は雲の下の青い散乱光と
  写真のホワイトバランスを含む。晴天の far_01 と ground_02 でも撮影の青みの足し方は写真の 0.3〜0.7 倍（far_01 0.17 と 0.25、ground_02 0.13 と 0.46）
  に留まる。空気遠近の散乱光の色が中立〜暖色（Mie の割合が大きい、または地表の反射の色が散乱光に入る）で、Rayleigh の青が足りない見込み。
- (b) far_01 の 4 km の崖の色度は撮影で R ÷ G 1.94〜1.99 と、写真（1.55）より赤い。遠景の帯も同じなので、霞の色に加えて岩肌の
  アルベドの赤みも桃色の一部を作っている。
- まとめ: 差 7 は (c)（空気遠近の散乱光の色）が主で、(b)（岩肌の赤みの強さ）が重なる。

## 既知の限界

- 写真の領域は固定の多角形で、低木・株の影・雲の切れ間を画素ごとに分けていない（地面の値は植生の被覆を含む）。
- 撮影の雲は写真の雲に合わせていないので、雲の領域は写真の雲と撮影の同じ所の空を比べている。
- 写真の領域の仰角と太陽からの角距離は、撮影の視点のカメラで近似した値（写真のカメラの記録が無い）。
- 雲の無い青空は写真と撮影の両方で雲の無い所に限ったので、cliff_01 は仰角 16〜17° の狭い帯だけで、地平線に近い空の値が無い。
- 写真の露出の記録（far_01 の f/8・1/200 秒・ISO 100）だけでは現像の明るさが決まらないので、写真と撮影の絶対の明るさは比べない。
