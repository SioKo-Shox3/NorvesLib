# 荒野の空と霞と、独立に書いた大気の正解との比較

荒野の正解の絵（SCN-WLR-*）で、エンジンの空と霞（SCN-WLR-ATMOS-DUMP の書き出し）を、エンジンのコードを写さずに
Hillaire 2020「A Scalable and Production Ready Sky and Atmosphere Rendering Technique」の定義から数値積分した正解と比べた記録。
判定日: 2026-10-18。ブランチ `feature/scene-launcher`。タスク SCN-WLR-ATMOS-REF。描画の値は変えていない。

## 道具

| 何 | どこ | 何をするか |
|---|---|---|
| `AtmosphereReference.py --verify` | `Scripts/Terrain/AtmosphereReference.py` | 論文の設定と、書き出しの設定の 2 組で正解を段 1 と段 2（歩数・方向の数・表の細かさをすべて倍）で求め、比べる量が 0.5 % 以内で一致すること、鉛直の光学的深さが解析解と合うこと、多重散乱の級数が収束すること、B の 2 回目の散乱の源が細かい求積で直接積んだ値と合うことを確かめる |
| `ReferenceCheck.py --atmos-ref` | `Scripts/Terrain/ReferenceCheck.py` | 書き出し（`<視点>.atmos.*`）と正解を、空の方向別の輝度・距離別の透過率と散乱光・地表の照度・多重散乱の表・写真の空で比べ、`<撮影の出力先>/atmos_ref_check.json` に書く |

正解の媒質は論文の定義どおり: Rayleigh（散乱のみ）と Mie（散乱と吸収）の指数分布、オゾンの 10〜40 km の三角形の層（吸収のみ）、
Rayleigh の位相関数と Mie の Henyey-Greenstein。太陽の透過率は Bruneton 2017 の (r, μ) の並びの表。多重散乱は 2 つの版で求める。

- **A（論文の近似）**: 2 次以上の散乱を等方とし、点の周りがすべてその点と同じ光を受けるとみなす（Ψ_ms = L_2nd / (1 − f_ms)）。
- **B（散乱の回数で足す版）**: 等方とも、周りの点が同じ光を受けるともみなさない。各回の散乱で本当の位相関数（Rayleigh・HG）を使い、
  方向別の放射輝度を次の回へ引き継ぐ。点（高度 × 太陽の天頂角の余弦）ごとに入ってくる光の放射輝度を向き別に持ち、散乱の源
  ∫ p(u·w) L(w) dw を「点の天頂角の余弦 × 太陽からの方位差」の表にし、次の回はその表を視線の上で引いて積む（地表の反射も回ごとに返す）。
  1 回目の光の Mie の前方の山（g = 0.8）と、2 回目の散乱の位相関数の山が重なる所は、球の上の畳み込み（ルジャンドル展開の係数の積。
  HG どうしは g の積の HG）で解析的に積む。高さフォグの散乱の源も、霧の HG（g は書き出しの値）で同じ光から作る。
- B の 2 回目の散乱の源は、点の周りの細かい向きの求積（太陽の向きを軸に天頂角 288 × 方位 360）で 1 回目の光を直接積んだ値とも比べる
  （`--verify` で 1 % 以内を合否に使う）。

設定はエンジンの書き出しの JSON から取る（惑星 6360 km・大気の厚さ 80 km・Rayleigh の地表の係数と尺度高さ 8 km・Mie の地表の消散係数
1.111e-4 /m と尺度高さ 1600 m・g 0.8・地表のアルベド 0.3）。書き出しに無い Mie の散乱と吸収の分け方（散乱 1.0e-4・吸収 1.11e-5 /m）と
オゾン（論文と同じ値）は `SkyAtmosphere.cpp` の設定値。値は太陽の照度 1 lux あたりで求め、大気の外の太陽の照度 133965 lux を掛けて比べる。

τ は光学的深さ（霧と空気遠近の Mie はエンジンの値、大気の Mie と Rayleigh はエンジンの空と同じ大気を高度 1474 m から積んだ値）。散乱光は cd/m² の輝度 Y（エンジンの空気遠近は霧の透過率を掛けた値）。仰角 0・2° の視線も含めた 1 km より先のすべての視線で、(霧 ＋ 空気遠近の Mie) ÷ 大気の Mie は 0.268〜0.594。

- **光学的深さ（透過率）では二重になっていない。** 高さフォグと空気遠近の Mie は同じエアロゾルの霞を表すが、足しても空の大気が同じ視線で
  持つ Mie の 0.27〜0.59 倍（地表への視線では 0.52〜0.59 倍）。空気遠近の Mie を密度 × 0.22 に下げ、その分を霧が受け持つ形で、
  合わせて空の大気の Mie の半分ほど。上向きの視線（仰角 2°）では霧が高さ 100 m で 1/e に減るので、霧の分が小さい。
- **散乱光では、太陽の光の一部を二重に数えている。** 霧の「空の LUT の色 × 不透明度」は、視線の向きの空の輝度（太陽の側では大気の
  1 回目の散乱の前方の山を含む）を霧の周りの光として使う。正解では霧の周りの光は向きに依らない多重散乱 Ψ で、太陽の側の霧の空の色の項は
  正解の 2.2 倍。その上に霧の太陽の単一散乱（正解の 0.9 倍）を足すので、太陽の側の霧の散乱光は正解の 1.3 倍（10 km）。
  反対の側では霧の空の色の項が正解の 1.1 倍で、二重はほとんど無い。
- 空気遠近の散乱光は、太陽の側で正解の 0.90 倍、横で 0.66 倍、反対の側で 0.56 倍（10 km）。空の LUT の地平線の輝度（大気の外まで
  積んだ光）の割合で配るので、近い区間の明るさの向きの差が足りない。

## 再現

```
python Scripts/Terrain/AtmosphereReference.py --verify
python Scripts/Terrain/ReferenceCheck.py --atmos-ref --capture .harness/runs/scene-capture/SCN-WLR-ATMOS-DUMP --verify
```

`--atmos-ref` は書き出し（SCN-WLR-ATMOS-DUMP の撮影）の入力のハッシュが今のファイルと合うこと、`--verify` の正解の収束の確かめが合格で
同じ設定であることを前提にし、同じ式で求まるはずの値（地表の太陽の透過率、同じ媒質の高さフォグと空気遠近の透過率）が正解と 2 % 以内で
合うことを確かめる（設定の読み違いを見つける）。散乱光と空の輝度の差は記録するだけで、合否には使わない。
