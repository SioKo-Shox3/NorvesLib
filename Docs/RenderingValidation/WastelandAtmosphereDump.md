# 荒野の空と霞の値の書き出し

荒野の正解の絵（SCN-WLR-*）で、エンジンの空と霞（空の LUT・前計算の表・空気遠近・高さフォグ・地表の照度）を、描画に使った
値そのままの浮動小数のファイルに書き出し、値どうしが揃うことを確かめた記録。判定日: 2026-10-18。ブランチ `feature/scene-launcher`。
タスク SCN-WLR-ATMOS-DUMP。描画の値は変えていない。

## 道具

| 何 | どこ | 何をするか |
|---|---|---|
| `--atmosphere-dump` | `Game/GameApplicationHandler.cpp`・`Game/Debug/MultiViewCapture.cpp`（開発ビルドだけ） | `--capture-views` の視点ごとに、PNG と同じフレームの空と霞の値を書く。描画の初期化の前に環境変数 `NORVES_ATMOSPHERE_DUMP=1` を置き、SceneView が `AtmosphereProbePass` を足す（ログに `ATMOSPHERE_DUMP`） |
| `AtmosphereProbePass` | `Library/Core/Public/Rendering/VolumetricsPass.h`（統計が有効な構成だけ） | 決めた視線ごとに、`volumetrics.frag` と共有の `Common/VolumetricsCommon.glsl` の式を `volumetrics_probe.frag` で評価し、事前露出の前の値を RGBA32F の 1 枚へ書く。定数は VolumetricsPass と同じ関数（`BuildVolumetricsParams`）で詰める |
| `SaveCapturedAtmosphere` | `Library/Core/Public/Rendering/FrameCaptureHdrWriter.h` | 撮影の読み出しの 1 枚と、そのフレームの空のパラメータから SkyAtmospherePass と同じ関数で作り直した LUT・表を書く |
| `CaptureScene.ps1 -GameArgs atmosphere-dump` | `Scripts/CaptureScene.ps1` | 視点が 1 つでも `--capture-views` の 1 回の起動で撮り、書き出しの揃いを確かめ、入力のハッシュ（inputs.json）を書く |
| `ReferenceCheck.py --atmos-dump` | `Scripts/Terrain/ReferenceCheck.py` | 揃い・視線の範囲・値の範囲と、書き出しが描画に使われた値であることを照らす |

## 書き出すもの（`<視点>.atmos.*`）

値は線形の Rec.709（D65）、放射輝度は cd/m²、照度は lux、ワールドは +Y が上の m。数のファイルは 32 bit 浮動小数（リトルエンディアン）の
生の並びで、形・軸・単位は `<視点>.atmos.json` に書く。

| ファイル | 中身 | 形 |
|---|---|---|
| `transmittance_lut.f32` | 空の透過率 LUT（GPU へ上げた半精度の値）。横 = 天頂角の余弦 (x + 0.5) / 幅、縦 = 高度の割合 y / (高さ − 1) | 32 × 128 × 4 |
| `radiance_lut.f32` | 空の放射輝度 LUT（cd/m²、正距円筒、GPU へ上げた半精度の値）。a は太陽円盤の中なら 1 | 128 × 256 × 4 |
| `transmittance_table.f32` | 透過率の前計算の表（光学的深さ）。行 = 高度（v² の並び）、列 = 天頂角の余弦（x\|x\| の並び） | 32 × 128 × 3 |
| `multiple_scattering.f32` | 多重散乱の表 Ψ_ms（太陽の照度 1 lux あたりの cd/m²）。行 = 高度（v³）、列 = 太陽の天頂角の余弦 | 8 × 32 × 3 |
| `sky_view.f32` | sky-view の表（cd/m²）。行 = 仰角（地平線の近くを細かく）、列 = 太陽からの方位差（太陽の側を細かく） | 80 × 40 × 3 |
| `probe.f32` | 決めた視線の高さフォグと空気遠近（下の行の約束） | 7 × 視線 × 4 |

視線（240 本）: 太陽の方位からの方位差 0・90・180・270° × 仰角 −5・−2・0・2・5・10・20・30・45・60・90° × 距離 0.3・1・3・10・30 km と、
同じ方位差 × 水平距離 0.3〜30 km の、カメラの 1.7 m 下の水平面（荒野の視点の目の高さ）の点への視線。

`probe.f32` の行: 0 = 高さフォグの透過率・不透明度・空気遠近の RGB 平均の透過率・合成のアルファ、1 = 高さフォグの色（空の放射輝度 LUT の
視線の向きの値）、2 = 高さフォグの太陽の単一散乱（影つき）、3 = 空気遠近の透過率、4 = 空気遠近の散乱光、5 = 空の放射輝度 LUT の値、
6 = `volumetrics.frag` がシーンの色へ足す光（高さフォグの色 × 不透明度 + 単一散乱 + 空気遠近の散乱光 × 高さフォグの透過率）。

JSON には、空・空気遠近・高さフォグのパラメータ（シェーダーに詰めた消散係数を含む）、エンジンの太陽の方向光、地表の太陽の照度
（大気の外・太陽に垂直・水平面）と空の照度（水平面）も書く。

## 気づいたこと（値は変えていない）

- 空の放射輝度 LUT は、半精度へ上げるときに 0.9 × 65504 = 58944 cd/m² で頭打ちになる（`SkyAtmospherePass.cpp` の `FloatToHalfRne`）。
  ref_ground_02 では太陽の周り（太陽から数度以内）の texel が頭打ちになり、頭打ちの前の sky-view の値は最大 83894 cd/m²。
  空の背景・高さフォグの色・空気遠近が引く LUT は、太陽の近くでこの上限の値になる。
- 高さフォグは、空の放射輝度 LUT の色 × 不透明度と、太陽の単一散乱の両方を足す。地表への視線ではこの 2 つがほぼ同じ大きさで、
  空気遠近の散乱光とも重なる（同じ霞を二重に数えているかは SCN-WLR-ATMOS-REF で内訳を調べる）。
- 共通化の前後で見た目は変わらない: SCN-WLR-BASELINE の ref_ground_02 と、画素の 99.96 % が同じ・PSNR 59.65 dB・平均輝度の差 0.0001。
