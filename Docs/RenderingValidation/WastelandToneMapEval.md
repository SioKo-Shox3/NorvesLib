# 荒野の表示変換の候補を、同じ HDR に掛けて比べる

荒野の正解の絵（SCN-WLR-*）で、表示変換（トーンマップとグレーディング）の候補を、SCN-WLR-DISPLAY-TRANSFORM の再現
（`Scripts/Terrain/DisplayTransform.py`）でエンジンの HDR と Cycles の HDR の両方に掛けて並べ、手本の写真と比べた記録。
比べて候補を選ぶだけで、エンジンの既定（荒野のカメラの差し替え）は変えていない。
判定日: 2026-10-19。ブランチ `feature/scene-launcher`。タスク SCN-WLR-TONEMAP-EVAL。

## 道具

| 何 | どこ | 何をするか |
|---|---|---|
| `Scripts/Terrain/ReferenceCheck.py --tonemap` | | 候補をエンジンと Cycles の HDR に掛け、写真の崖・地面の枠で表示の値を測り、`tonemap_check.json`・視点ごとの比較画像 `tonemap_<視点>.png`・一覧 `tonemap_overview.png` を書く |
| `Scripts/Terrain/DisplayTransform.py` | | エンジンの表示変換の再現（SCN-WLR-DISPLAY-TRANSFORM で撮影と 8 bit で 1 段以内に合わせたもの）。候補はこの式の演算子とグレーディングの値だけを差し替える |

## 条件

- エンジンの HDR: 既定の荒野（照明・大気・雲・植生・建物すべてあり）を SCN-WLR-BASELINE と同じ条件
  （`CaptureScene.ps1 -Scene wasteland -Configuration RelWithDebInfo -Hdr`、1920×1080）で手本の 6 視点を撮ったもの
  （`.harness/runs/scene-capture/SCN-WLR-TONEMAP-EVAL/`）。SCN-WLR-BASELINE の保存した撮影（2026-10-16）は描画のコードが変わって
  入力のハッシュが古くなっていたので、同じ条件で撮り直した。基準そのものは上書きしていない。
  各視点の HDR は PNG と `--hdr` と同じ検査で合い、撮影の表示変換の記録は候補 current と同じ値。
- Cycles の HDR: SCN-WLR-CYCLES-LIT の実材質の地形（共通の照明・地形だけ。`WastelandCyclesLit.md`）。空（透明の背景）は共通の照明の
  一様な空の放射輝度で埋め、露出はその撮影のプリエクスポージャ（エンジンと同じ 9.43e-5）。
- 候補（露出・コントラストの支点 0.18・VignettePass〔強さ 0.25・半径 0.85・柔らかさ 0.6〕は撮影の値のまま。ブルームと FXAA は
  入れない）:

| 名前 | トーンマップ | グレーディング |
|---|---|---|
| current | NeutralLinear（今の荒野） | 式 1、コントラスト 1.35・彩度 1.2・色温度 0.05（今の荒野） |
| neutral_mild | NeutralLinear | 式 1、コントラスト 1.15・彩度 1.1・色温度 0.05 |
| neutral_plain | NeutralLinear | 中立（コントラスト 1・彩度 1・色温度 0） |
| aces20_lut | ACES 2.0 SDR の LUT | 掛けない（LUT が表示変換そのもの） |
| aces_filmic | ACES Filmic の近似の曲線（エンジンの既定の演算子） | 中立 |

- 測り方: HDR を 1280×720 へ面積の平均で縮めて表示の値を作り、写真の崖・地面の枠（`CompareReference.py` の PHOTOS）の地形の画素で、
  符号化した輝度の p05・p50・p95 と幅（p95 − p05）、彩度（HSV の S の平均）、白飛び（どれかの成分が 254 以上）、崖 ÷ 地面の輝度の比、
  地面の R/G・B/G を測る。露出は 2 通り: 撮影の露出のままと、枠の中の明るさの中央値を写真に合わせた露出（候補ごと・視点ごとに
  プリエクスポージャへ 2^s を掛ける s を探す）。後者は曲線の形と色だけを比べるためのもの。
- 点数: 量ごとに、写真との差の絶対値の 6 視点の平均を求め、5 候補の平均で割り、量の数で平均した値（1 が候補の平均、小さいほど
  写真に近い）。使う量は中央値（撮影の露出のときだけ）・幅・彩度・崖 ÷ 地面の比の対数・地面の R/G・地面の B/G・白飛び。

### 見て分かったこと

- **今のグレーディングは 4 組すべてで最も写真から遠い。** 彩度 1.2 と色温度 0.05 が地面を赤く振り（地面の R/G 3.30、写真 2.18。
  露出を合わせると 3.88）、彩度の平均が写真の 0.47 に対して 0.63〜0.69。コントラスト 1.35 は明部を押し上げ、撮影の露出のまま
  エンジンで 5.9 %・Cycles で 14.1 % の画素が白飛びする（他の候補は 0.0 %）。絵でも current だけ地面が橙に飽和し
  （ref_cliff_01・ref_far_02・ref_ground_01 が目立つ）、ref_cliff_01 の崖は橙一色で写真の赤茶と白い帯の分かれが見えにくい。
  Cycles の HDR に掛けても同じ向きなので、エンジンの照明や材質ではなくグレーディングが原因。
- **NeutralLinear の中立と ACES 2.0 の LUT は、形と色では同じくらい写真に近い**（点数 0.56〜0.90 で 1・2 位を分け合う）。
  違いは明るさ: ACES 2.0 の LUT は同じ露出で中間調が約 0.8 段暗く（中央値 0.42 と 0.54）、空が灰色にくすむ。
  露出を合わせると、エンジンの HDR では ACES 2.0 が影の中の植生と礫を沈め（黒つぶれ ref_ground_01 で 2.1 %、ほかの視点 0〜0.4 %）、
  NeutralLinear は影を縮めない（0.01 % 以下）。
- **ACES Filmic（エンジンの既定）は明部の彩度が落ち**（Cycles の撮影の露出で彩度 0.33、空と日なたの地面が白っぽい）、露出を
  合わせると逆に彩度が上がって地面が赤くなる。どちらでも中位以下。
- **表示変換で埋まらない差**: 露出を合わせても、明るさの幅は写真 0.47 に対しエンジン 0.31〜0.39・Cycles 0.23〜0.29 で、どの候補も
  狭い。崖 ÷ 地面の比の差（対数で 0.50〜0.61）は 5 候補でほとんど変わらない。これらは曲線ではなく、照明・天気・写っている物
  （下の条件の違い）と中身の差で、表示変換を替えても直らない。コントラストを上げて幅を合わせると、current のように彩度と
  白飛びが先に崩れる。

### 条件の違い（写真の現像を含む）

- 写真の現像（カメラの露出・ホワイトバランス・トーンカーブ・彩度の設定）は分からない。撮影の露出のままでは、6 視点の平均で
  どの候補も写真より明るい（露出を合わせる差 NeutralLinear で約 −1 段、ACES 2.0 で約 −0.2 段）が、これは写真の露出の決め方の差を
  含むので、露出そのものは選ぶ根拠にしない（露出を合わせた組と合わせない組の両方で順位を見た）。
- 写真は天気・時刻・太陽の向きがエンジンの照明と違い（薄曇りの ref_far_02・ref_ground_01、逆光の ref_ground_02 など）、
  植生・礫が写真の地面の色を変える。Cycles は地形だけ・一様な空で、空の色と霞は比べられない（空は枠の外）。
- 写真の地面の R/G（1.88〜2.56）は視点ごとに大きく違い、エンジンの材質の色の差と現像の差を分けられない。色温度の候補は
  0 と 0.05 だけで、白色点の合わせ込みはしていない。

## 採る候補と理由

**neutral_plain（NeutralLinear のまま、グレーディングを中立〔コントラスト 1・彩度 1・色温度 0〕にする）を採る。**

1. 写真との差が 4 組すべてで 2 位以内（エンジンの露出を合わせた組・Cycles の撮影の露出の組で 1 位）。今の current に比べ
   点数が 0.29〜0.66 倍で、地面の赤の振れ（R/G）と彩度の過多と白飛びがすべて消える。
2. トーンマップの曲線と露出が今の荒野と同じなので、変えるのはカメラの差し替えのグレーディングの 3 つの値だけで済む。
   中間調までは線形なので、荒野の露出（プリエクスポージャ）とほかのシーンの値を移し替えなくてよい。
3. ACES 2.0 の LUT は形と色では同等だが、同じ露出で約 0.8 段暗く空がくすむので、採るなら荒野の露出の移し替えと全視点の
   撮り直しが要る。影を縮めない NeutralLinear を選んだ理由（`WastelandRoutine.cpp` の日中のグレーディングの注記）とも合う。
   露出の決め方を作り直すときの次点として残す。

残る差（明るさの幅が写真より狭い、崖 ÷ 地面の比）はグレーディングで埋めず、照明・空・霞・植生の項目で扱う
（SCN-WLR-GAP-LIST で「条件不一致・未判定」と「中身の欠陥」へ振り分ける）。エンジンの既定とこの項目での荒野の値は変えていない。
