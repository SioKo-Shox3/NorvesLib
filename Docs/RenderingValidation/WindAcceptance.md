# 通常メッシュの風の頂点アニメの受入れ

## 実装の範囲

通常メッシュの材質 `VertexAnimationParams` は次の値を持つ。単位のある高さはオブジェクト座標の Y で、振幅と高さの単位は m。

| 項目 | 範囲 | 既定 |
|---|---|---|
| `Mode` | `None = 0`、`Grass = 1`、`Tree = 2` | `None` |
| `Amplitude` | [0, 5] | 0.1 |
| `HeightStart` | 有限値 | 0 |
| `HeightEnd` | 有限値、`HeightStart + 0.001` 以上 | 1 |
| `FrequencyScale` | (0, 8] | 1 |
| `BranchFactor` | [0, 2] | 0.3 |
| `PhaseRandom` | [0, 1] | 1 |
| `Stiffness` | [0, 1] | 0.5 |

`SanitizeVertexAnimationParams` は範囲外・非有限の値を既定値に戻す。`HeightEnd` が非有限なら整えた `HeightStart + 1` を使い、下限に満たなければ `HeightStart + 0.001` にする。`None` は GPU の材質値を全て 0 にする。

`Common/VertexAnimation.glsl` は風速 5 m/s を強さ 1 の基準とし、強さを 3 以下にする。高さの幅を `span = max(HeightEnd - HeightStart, 0.001)` とし、高さマスクは `h = clamp((localY - HeightStart) / span, 0, 1)` と `heightMask = pow(h, mix(1, 3, Stiffness))`。草の茎は基準 0.75 Hz、木の幹は 0.25 Hz で `amplitude * strength * heightMask * (0.7 + 0.3 * sin(位相))` の風向変位を加える。木の枝先は高さ `h` とローカル XZ の幹軸からの距離を使う `clamp(length(localXZ) / (0.5 * span), 0, 1) * h` のマスクで、基準 1.5 Hz の揺れを `BranchFactor` 倍し、風向と上向きをそれぞれ 0.5 倍した方向へ加える。枝先の位相には頂点のローカル位置も使う。CPU が境界の余裕に使う風の最大変位は `Amplitude * 3 * (1 + BranchFactor)`、`None` なら 0。

個体差の位相はワールド行列の現在の平行移動を 0.25 m セルに分けたハッシュと `PhaseRandom` から作る。各正弦の周波数は `FrequencyScale` を掛けて 1/4096 Hz の整数倍（最小 1/4096 Hz）に量子化し、時刻は 4096 秒で折り返す。風の突風・乱流は別の値ノイズで、同じ正弦の周期性を持たないため、時刻の折り返しで連続する保証はない。

GBuffer は 1 回の記録で共通の風の UBO を 1 つ借り、材質ごとに頂点アニメの 2 欄を渡す。CSM・点光源の不透明な影は描画の定数として風と材質を渡し、点光源では面内の同じ材質で記述子を共有する。VSM は風を描画 UBO、材質を塊ごとの表で渡す。通常メッシュの GBuffer・不透明な CSM・点光源の影・VSM は同じ `ApplyVertexAnimation` を使い、VSM の切り抜きにも風が入る。

velocity は現在と前に描いた時刻の位置をそれぞれ評価し、前の位置の評価にも現在のワールド原点を使う。インスタンスの試験用正弦と材質の風は独立しており、両方が有効なら正弦の後に風を足す。可視バッファが On の場合は頂点アニメの材質を ID のラスタと解決から外し、解決後に GBuffer へ重ね描きする。

## 既知の限界

- MegaGeometry は材質の風の対象外で、静的な姿勢のまま。スキニングにも材質の風を入れない。
- 切り抜き（Masked）の CSM・点光源の影は風で変位しない。VSM の切り抜きは風で変位する。
- 頂点色が未対応（GR33）のため、木の変位マスクは高さと幹軸からの距離で近似する。法線は変位に合わせて傾けない。
- RT・パストレーサーは風による変位を使わず静止姿勢を使う（GR104）。
- 風が有効で頂点アニメ材質を持つ VSM の投影物は、対象範囲のキャッシュを毎フレーム無効にして再描画する。風の有効・無効の切り替えでも古い範囲を無効にする。
- 影の頂点アニメの GPU 時間は `G5-GR46-WIND-CHECK` で記録する。

## 人が見るときの見どころ

開発ビルドの Game を起動してランチャーから `grassland`（草原）を選ぶか、リポジトリのルートから `build/Game/Debug/Game.exe --scene=grassland` で直接入る。開始カメラ前方の仮の木 4 本は地形の高さを取得した後に配置される。材質は `Tree`、振幅 0.25、開始高さ 0.5、終了高さ 5.5、周波数倍率 1、枝の倍率 0.4、位相差 1、硬さ 0.4。環境は +X 向き、基準風速 3.5 m/s。

- 4 本が風で揺れ、地面に落ちる木の影も揺れに合わせて動く。
- `build/Game/Debug/Game.exe --scene=grassland --visibility-buffer=on` でも木の揺れが消えない。
- 環境の風を無効にするか材質の `Mode` を `None` にし、試験用の正弦も無効にした物は、風による変位をしない。既存の草原にはこの比較用の固定された木や風を止める専用の起動引数は用意されていないため、条件を設定できる場合に見る。

この作業では撮影・GPU の計測・試験は回していない。
