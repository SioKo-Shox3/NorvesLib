# 荒野のグレーディングを中立にした結果（SCN-WL-GRADE-NEUTRAL）

荒野の昼のグレーディングを、コントラスト 1.35・彩度 1.2・色温度 0.05 から、コントラスト 1・彩度 1・色温度 0 に変えた。
トーンマップ（NeutralLinear）・露出（EV100 13.6 + 0.49）・ビネットは変えていない。夜の集落と、ほかのシーンのグレーディングも変えていない
（値は `Game/GameModes/Wasteland/WastelandRoutine.cpp` の荒野のカメラだけが持つ）。採った候補は `WastelandToneMapEval.md` の `neutral_plain`。

## 検査（`ReferenceCheck.py --grading`、本体は `Scripts/Terrain/GradeNeutral.py`）

既定の荒野の撮影（RelWithDebInfo・1920 × 1080・`-Hdr`）の視点 ref_cliff_01・ref_ground_02 で次を検査する。

- 撮影の表示変換の記録が候補 `neutral_plain` と同じ値（演算子・グレーディングの式・コントラスト・彩度・色温度・明るさ・色フィルタ）。
- HDR に `neutral_plain`（`DisplayTransform.py` の再現）を掛けた画と、撮影の PNG が 8 bit で 1 段以内に合う。既定の撮影の PNG にはブルームと FXAA が乗り、
  HDR（ブルーム前）から全画素は再現できないので、`--hdr` と同じ「ブルームの影響が小さく平らな暗い画素」で照合する。
  結果は 2 視点とも選んだ画素の 99.999 % が範囲内（p99 の差は 0.74・0.93 段）。全画面の一致率（ブルームの画素を含む）は 0.945・0.934 で参考値。
- 同じ HDR に変更前の表示変換（候補 `current`）を掛けた画を「前」、撮影の PNG を「後」として、写真の崖・地面の枠の地形の画素で
  地面の R/G・彩度・白飛びの割合（8 bit で 254 以上の成分がある画素）を測る。
