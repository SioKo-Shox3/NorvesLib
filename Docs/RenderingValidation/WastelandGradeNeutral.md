# 荒野のグレーディングを中立にした結果（SCN-WL-GRADE-NEUTRAL）

荒野の昼のグレーディングを、コントラスト 1.35・彩度 1.2・色温度 0.05 から、コントラスト 1・彩度 1・色温度 0 に変えた。
トーンマップ（NeutralLinear）・露出（EV100 13.6 + 0.49）・ビネットは変えていない。夜の集落と、ほかのシーンのグレーディングも変えていない
（値は `Game/GameModes/Wasteland/WastelandRoutine.cpp` の荒野のカメラだけが持つ）。採った候補は `WastelandToneMapEval.md` の `neutral_plain`。

## 検査（`ReferenceCheck.py --grading`、本体は `Scripts/Terrain/GradeNeutral.py`）

既定の荒野の撮影（RelWithDebInfo・1920 × 1080・`-Hdr`）の視点 ref_cliff_01・ref_ground_02 で次を検査する。

- 撮影の表示変換の記録が候補 `neutral_plain` と同じ値（演算子・グレーディングの式・コントラスト・彩度・色温度・明るさ・色フィルタ）。
- HDR に `neutral_plain`（`DisplayTransform.py` の再現）を掛けた画と、撮影の PNG が 8 bit で 1 段以内に合う（`--display` の scene の組と同じ基準: 画面全体の画素の 99 % 以上）。
  既定の撮影の PNG にはブルーム（6 段の縮小・拡大、しきい値なしで 4 % 混ぜる）と FXAA が乗るので、撮影の記録（`hdr.json` の `post`）どおりに
  `Scripts/Terrain/PostEffects.py` で再現して掛ける（シェーダーの式・段の大きさ・RGBA16F への丸め・双線形の副テクセル 8 bit をそのまま写す）。
  結果は画面全体で ref_cliff_01 が 99.96 %、ref_ground_02 が 99.93 %（ブルームと FXAA を再現しないと 94.5 %・93.4 %）。
- 同じ HDR に変更前の表示変換（候補 `current`。ブルームと FXAA も同じに再現）を掛けた画を「前」、撮影の PNG を「後」として、写真の崖・地面の枠の地形の画素で
  地面の R/G・彩度・白飛びの割合（8 bit で 254 以上の成分がある画素）を測る。

## 6 視点を並べて開いた所見

`.harness/runs/scene-capture/SCN-WL-GRADE-NEUTRAL-6views/grading_sheet.png`（写真｜前｜後）を開いた。

- 後は、前に見られた地面・崖の強い橙の色づけと、空・雲の白飛びが消えた。崖の暗部は締まりが減って写真の崖に近い明るさで読める。
- まだ写真と違う所（グレーディングでなく照明・中身の差として、`WastelandGapList.md` の項目へ残す）: 地面が写真より橙で明るい（ref_far_01・ref_ground_01 は R/G が写真より高いまま）、
  空の青みが写真より薄い（ref_ground_02・ref_cliff_02 は白い）、ref_ground_02 の空に水平の継ぎ目の帯がある、植物と地面の質感の違い。
- 6 視点の撮影の PNG も、画面全体で HDR にブルーム・表示変換・FXAA を掛けた画と合う（±1 段の画素が 99.62〜99.99 %。検査は 6 視点とも pass）。
