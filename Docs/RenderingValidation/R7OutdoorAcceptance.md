# R7屋外受入れ判定

判定日: 2026-09-25。R7-O3（空・霧込みの屋外シーンのPT/raster相互比較）を受入れる。`R7OutdoorPathTracingReferenceVulkanTest`は朝・昼・夕の3時刻すべてで知覚差（LDR-FLIP）の閾値内にあり、閾値の物差しの単調性と2つの負の対照も満たす。全輸送との差は既知差として量を記録する。

## 比較の方法

- **シーン**: 屋外の検証シーン（地面と5つの球）の方向光を消し、R2の空（朝: 高度8°・方位−35°、昼: 45°・0°、夕: 15°・35°）とR3の高さフォグ（密度0.005）を有効にして、空の太陽だけで照らす。露出はf/16・1/125 s・ISO 100。256×256。
- **ラスタ**: RTGI（拡散2バウンス）、直接光は解析BRDF（PTと同じ）。静止カメラでRTGIの履歴延長が終わるまで待って取得する。
- **判定の参照**: R6と同じく、ラスタの近似が実装する輸送に揃えたPT（`--path-tracing-transport=two-diffuse-bounces`）。1次面は直接光（全BRDF）と環境の鏡面反射（物体に当たる方向は0。ラスタのIBLの鏡面反射に当たる）、経路は拡散葉だけで2回まで散乱し、散乱光線の命中面はLambertの直接光で照らす（RTGIの命中点と同じ）。
- **参照の推定**: PTの放射輝度の参照（拡散2バウンス・全輸送・直接光のみ）は独立な試料の組（`--path-tracing-sample-batch`）を3枚描き、画素ごとに輝度が中央の組の値を使う（median of means）。まれな1試料の外れ値を参照から外すため（ユーザーの判断）。各組は最低1536試料で、実測は3584〜8192試料。
- **閾値**: 参照のうち直接光のみに入らない成分（面が受ける空の光と相互反射）を一様に±20%変えた画像と参照との知覚差のうち小さい方。判定は原寸のFLIP平均、一致画素の原寸の画素単位FLIP最大、8×8区画平均のFLIP最大の三つ。±40%の変化が3つとも閾値の外にあること、参照の最も暗い画素へ平均輝度の4倍の光を足した局所欠陥が画素単位最大だけで閾値の外に出ることを比較のたびに確かめる。
- **一致画素**: 画素単位最大は、幾何（ラスタのGBufferとPTの1次命中の距離1%以内・法線の内積0.99以上）と太陽の可視（ラスタのCSMの係数`--r7-outdoor-debug-view=sun-visibility`、PTの光線`--path-tracing-debug-output=sun-visibility`）がともに一致する画素で求める。可視の差が0.2（PTの可視の最低64試料での標準偏差の上限1/16の約3倍）を超え、かつPTの可視の縁から2画素以内の画素を、影の縁で判定が分かれた画素として除き、数を記録する（ユーザーの判断）。影の内側（縁から3画素以上）の1画素でラスタの可視を1にした画像が除外されずに残ることを比較のたびに確かめ、満たさなければ不合格とする。

## 既知の方式差（全輸送との差）

判定には使わず量を記録する（`_known_`の行）。

| 時刻 | ラスタ 対 全輸送（平均 / 一致画素最大 / 区画） | 参照 対 全輸送（平均 / 一致画素最大 / 区画） |
|---|---|---|
| 朝 | 0.0127 / 0.1496 / 0.0664 | 0.0054 / 0.1602 / 0.0665 |
| 昼 | 0.0168 / 0.1896 / 0.0710 | 0.0057 / 0.2080 / 0.0760 |
| 夕 | 0.0164 / 0.2364 / 0.0993 | 0.0080 / 0.2345 / 0.1106 |

1. **3回目以降のバウンス**: 球の下の接地部では、全輸送の間接光が拡散2バウンスの約1.5倍になる（地面と球の下側の間の相互反射）。RTGIは拡散2バウンスまで。
2. **光沢のある相互反射**: 夕の緑の球の影側の面は、隣の球の日向の面での太陽の鏡面反射で照らされる。RTGIの命中点はLambertだけで、PTの命中点をLambertにすると差は消える（ラスタ/PT 0.99〜1.00）。
3. **影の縁**: ラスタのCSMの可視は球の明暗境界で約3画素かけて下がり（例: 0.96→0.65→0.48→0.18）、PTは1画素で1→0に変わる。上の除外の対象。
4. **斜めの地面の鏡面反射**: 昼の地平線近くの地面で、ラスタのIBLの鏡面反射の分だけ間接光が全輸送の約1.5倍になる（朝・夕は1.07〜1.11倍）。判定の参照との差は閾値内。
5. **霧**: ラスタの霧はCSMを使う1次光線の合成で、PTはRTの可視で散乱光線の区間にも掛ける（`R7FogTransport.md`）。
