# 荒野の遠景のぼけを静止の撮影で切り分ける

荒野の遠くの崖がぼけて見える原因を、条件を 1 つずつ変えた静止の撮影で切り分けた記録。判定日: 2026-10-19。
ブランチ `feature/scene-launcher`。タスク SCN-WLR-FAR-BLUR-STATIC。既定の見た目は変えていない（条件はすべて開発ビルドの起動引数）。

## 測り方

- 正解: 同じ視点を 2 倍の解像度（3840×2160）・AA なしで撮り、線形の光で 2×2 を平均して 1920×1080 へ縮めた画（超標本化）。
  4K は描画先が大きく VRAM のジオメトリの取り分の目標が縮むので、取り分だけ広げる（`--vram-geometry-share=9`。描くものは変えない）。
- 範囲: 正解の深度が 1000 m より奥の地表（2×2 のすべてが奥）を遠景、そのうち法線の |y| が 0.8 未満の面を崖とする。
  範囲の外（空・近景）から 2σ 画素以内は数えない（空との輪郭の強い縁が帯域に漏れるため）。
- 帯域: 表示の値（PNG の符号化のまま）の輝度を、隣り合うガウスの差 G(σk) − G(σk+1)（σ = 0・1・2・4・8 画素）の 4 帯域に分ける。
- 帯域ごとに、条件の帯域を正解の帯域へ射影した利得 g（細部の残り。1 − g が細部の欠け）と、射影の残り（正解に無い成分）の
  量 ÷ 正解の量（エイリアス）を求める。エイリアスは鮮明さに数えない。細かい 2 帯域（σ 0〜1・1〜2）を正解の量で重み付けて
  まとめた値を表に載せる。
- 較正: 正解を σ 0.8 でぼかした画は細部の欠けに（帯域 0 の欠け 0.3 以上・エイリアス 0.05 以下）、正解に白色雑音を足した画は
  エイリアスに（帯域 0 の残り 1 ± 0.05・エイリアス 0.3 以上）数えられることを、視点ごとに確かめる。
- 撮影の確かめ: 組ごとに、条件を替える起動引数が約束どおりで、Game のログに差し替えの印があり（既定の組には無く）、
  撮った時点でジオメトリのページの要求が残っていない（`GEOMETRY_PAGES` の wanted 0）こと。荒野は仮想テクスチャを使わない
  （`VRAM_POOLS` の `vt_used_mb` がどの行も 0）ので、VT の常駐の待ちは要らないことをログで確かめる。全組が同じ入力のハッシュで撮れていること。

検査: `python Scripts/Terrain/ReferenceCheck.py --blur-static --capture .harness/runs/scene-capture/SCN-WLR-FAR-BLUR-STATIC --verify`。
結果は `blur_static_check.json`、切り出しの並びは `blur_<視点>.png`。

## 条件

| 組 | 起動引数 | 変えるもの |
|---|---|---|
| base | なし | 既定（FXAA・霞あり・内部解像度 1・LOD 既定・ミップの偏り 0・異方性 16） |
| aa-taa | `--wasteland-aa=taa` | AA を TAA に（静止なので履歴は貯まりきる） |
| aa-none | `--wasteland-aa=none` | FXAA のパスを外す |
| haze-off | `--wasteland-hide=aerial+fog` | 空気遠近と高さフォグを切る |
| scale-075 | `--wasteland-render-scale=0.75` | 内部解像度 0.75 |
| mip-bias-m1 | `--terrain-mip-bias=-1` | 地形の材質のサンプラーのミップの偏り −1（ラスタと可視バッファの解決の両方） |
| aniso-1 | `--terrain-anisotropy=1` | 地形の材質のサンプラーの異方性を切る（等方の線形） |

地形の LOD を最細に固定する組（`--wasteland-finest-lod`）は、2 視点の読み込みが 10 分たっても落ち着かず撮れなかったので、
SCN-WLR-FAR-BLUR-LOD で撮る。scale-075 は HDR が内部解像度（1440×810）で書かれ撮影の大きさの照合に落ちるため `-Hdr` なしで撮り、
入力のハッシュは `ReferenceCheck.py --record-inputs` で書いた（比べるのは PNG だけ）。

帯域ごとの細部の残り（base、σ 0〜1・1〜2・2〜4・4〜8）: ref_far_01 0.73・0.84・0.91・0.97、ref_cliff_02 0.65・0.77・0.85・0.89。

正解は筋が細く続いて見えることを確かめた。

## 原因の順位

2 視点の平均で、既定との差（細部の欠け / エイリアス）。

1. **画素あたりの標本の不足（エイリアス）**: 既定のエイリアスが正解の量の 0.64〜0.81 倍あり、細部の欠け 0.23〜0.31 より大きい。
   内部解像度を 0.75 に下げると欠けが +0.279 増え、2 倍で撮った正解との差の大半は 1 画素 1 標本の描き方そのものから来る。
   遠景の「ぼけ」に見えるものの多くは、細い筋が標本の間に落ちて途切れる・階段になることによる。
2. **霞**: 遠景の帯域の量を全帯域でほぼ一様に 0.74〜0.87 倍に下げる（コントラストの低下。帯域の形は変えない）。
   空気遠近の散乱光が正解の 0.56〜0.90 倍である（SCN-WLR-ATMOS-REF）ことと合わせ、霞の量そのものは過大ではないが、
   コントラストを落とす分だけ鮮明さの印象を下げる。
3. **TAA**: エイリアスを半分（−0.316）に減らす代わりに細部の欠けを +0.117 増やす（σ 0〜1 の残りが 0.73 → 0.55）。静止でこの欠けなので、
   履歴の再投影の補間か近傍の色の押さえ込みが細部を削っている（動きの分は SCN-WLR-FAR-BLUR-MOTION）。
4. **効かないもの**: FXAA の有無（欠け −0.007・エイリアス +0.042）、地形の材質のミップの偏り −1（−0.004・−0.003）、異方性フィルタ（−0.001・0.000）。
   遠景の崖の細部は材質のテクスチャではなく、ジオメトリと陰影の側にある。

## 直す案

- 遠景の標本を増やす: TAA の静止の収束を正解に近づける（再投影の補間を Catmull-Rom などの鋭い補間に、近傍の押さえ込みを分散の箱に、
  ジッタの列を 8 以上に）。静止で欠けが base 以下・エイリアスが TAA 並みになることを同じ測り方で確かめる。
- 余力があれば遠景だけ標本を増やす（崖の稜線と急な面の画素だけ 2 標本にする、など）か、解像度を上げる経路（DLAA 相当）を比べる。
- 材質のミップの偏りと異方性は変えない（効果が測れない）。霞の量は SCN-WLR-ATMOS-REF の差の扱いで決める。
- LOD の固定の効き（SCN-WLR-FAR-BLUR-LOD）が大きければ、遠景の LOD の誤差の閾値を先に見直す。
