# 試験について

このライブラリでは試験を作らない・回さない。

- このライブラリは機能を作っている途中で、外の利用者も、それに頼って動く本番も無い。試験は守るものが無く、作り直しのたびに直す手間だけがかかる。
- 確かめはビルドが通ることと、人がゲームを動かして使ってみること。
  - 構成: `cmake -B build -S .`
  - ビルド: `cmake --build build --config Debug`
- 見た目と動きは人がゲームで確かめる。Game を起動するとランチャー(シーン選択)が出て、各シーンへ入れる。`--scene=<id>` でランチャーを飛ばして直接入る。
