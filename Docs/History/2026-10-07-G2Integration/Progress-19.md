  負荷モード default: (off, on) 88.745 dB・86 画素・最大 8、(off, on2) 80.89 dB・271 画素・最大 20、(off2, on) 74.47 dB・217 画素・最大 56、(off2, on2) 74.58 dB・341 画素・最大 56。off 同士（74.24）・on 同士（80.66）と同じ水準で、on と off の間に off 同士以上の差は無い。near は 0〜2 画素（±1）、low は 0。
  照合はソフトが描く画素の足あとで行った（ID の集合の代わり）。一時的に `visbuffer_sw_raster.comp` の `atomicMin` を止めて On で撮り（`-GBufferDebug Albedo`）、通常の On との Albedo の差を足あととした。足あとは起動画面 default 57 画素（22 成分。最大 25 画素）、負荷モード default 438 画素（201 成分。最大 132 画素）、near・low は 0。成分は 8 近傍で連結した画素の塊。足あとの手法の限界: 止めたソフトの画素の位置にハードが同じ Albedo の奥の面を描いていると差が出ず取りこぼす（負荷モードの near・low は `SW_RASTER_BIN` の `zeroed` が 40・22 なのに足あと 0。default は 583 クラスタで 438 画素）ので、足あとは下限で、この節の「足あとの中・外」はその前提で読む。
  起動画面: |差|≥2 の 1 画素は足あとの中（距離 0）。±1 の 25 画素は足あとから中央値 41 画素・最大 543 画素離れて散る（符号は +1 が 8・−1 が 18 で、一様な倍率の変化ではない）。負荷モード: 足あと +3 画素の中の差は (off, on) で 25/86、(off, on2) 27/271、(off2, on) 31/217、(off2, on2) 20/341 で、off 同士でも 16/255、on 同士 32/285。足あとからの距離の分布も off 同士と on・off で同じ（中央値 22〜92）。`analysis-footprint.txt`・`analysis-distance.txt`・`analysis-sign.txt`。
- 差の出どころ（GBuffer と RTGI）: GBuffer の Albedo・Normal は on と off で完全一致（起動画面 default・負荷 default の Albedo。起動画面の Normal）。Depth は 8bit の可視化で ±1 の画素が起動画面 default で 9（足あとの中）・負荷モード default で 29 だけ。ソフトとハードで被覆は同じで、深度の補間の小さなずれ（テストで最大 5.48e-6〜1.15e-5）だけが残る。**`-Rtgi Off` で起動画面 default の on と off は差 0 画素**（最大差 22 の 1 画素も、遠くの ±1 の 25 画素も消える）。ソフトの画素の小さな深度のずれが RTGI を通って足あとの中の色を変える（最大差 22 の 1 画素と足あと +2 画素以内の 9 画素）。足あとから遠い ±1 は RTGI の画面空間の処理（3×3）の届く範囲ではなく、画面全体で 1 つの値（露出）を通ったもので、次の節で確かめた。`analysis-gbuffer.txt`・`analysis-nortgi.txt`。
- (3) 大きなクラスタ: 差の連結成分は最大で 23 画素（負荷 default の off2 と on2）で、面で出る差は無い。中央の大きな球など、ソフトに回していないクラスタの上の差は ±1 の散在で、上の RTGI 経由のもの。TAA の撮影で見えた「中央の大きな球の約 33%」のような広い差は FXAA では出ない。
- 露出の入力: `AutoExposurePass` のログ（frame・avg_log2_luminance・target・adapted を小数 3 桁）は、起動画面 3 視点・負荷モード 3 視点のそれぞれで、off 2 回・on 2 回のすべてで完全一致（`analysis-exposure-log.txt`）。ソフトは露出の入力を約 0.001 EV では動かしていない（小数 3 桁での比較。ビット列で比べた結果は次の節で、0.001 EV 未満の差はある）。
- TAA の負荷モードの on1・on2 だけの状態（off の 4 回のどれにも無い、off と 65.5〜66.9 dB）の判断: **露出の入力の変化だけでは on 固有の原因と言えない**（小数 3 桁のログの一致は 0.001 EV 未満の差を否定しない。ビット列では、on と off の差が起動画面 default の 13 フレームに 1 ULP の大きさで出る。負荷モードでは off 同士も最後の桁が揺れる。次の節）。ソフトが入れる種は、ソフトが描いた画素の深度の小さなずれ（テストで最大 5.48e-6〜1.15e-5）が RTGI を通るものだけで、起動画面で 25 画素の ±1 と足あとの中の 1 画素。この種が TAA・RTGI の時間方向の履歴で別の状態へ広がった可能性は残るが、FXAA の結果（on 同士の揺れが off 同士と同じ水準）では on 固有の状態は示せず、4 回ずつの比較は状態の揺れと区別できない。TAA の撮影の on と off の PSNR は、on・off の判定に使わない。
