# R3-P3 停止記録 — 2026-09-20

## 決めたいこと
`shadowed-shafts` GPU検証で使う高さフォグを有効化するGameThread→RenderThread設定経路を、このタスクの許可パス外へ追加できるか。

## 確認した事実

- `VolumetricFogParameters::bEnabled` の既定値は `false` で、`MakeDefaultVolumetricFogParameters()` は既定値を返す。
- `VolumetricsPass::Declare()` は `SnapshotScene->VolumetricFog.bEnabled` が false の場合にパスを宣言しない。
- `RenderWorld` と `RenderingCoordinator` にある環境設定APIは `SetSkyAtmosphere` までで、volumetric fog setter はない。FramePacketの `Scene` は RenderWorld/Coordinator が構築する。
- 指定された fixture はカメラ・遮蔽物・ライトを設定できるが、`FramePacket.Scene.VolumetricFog` を設定できない。したがってfogが無効のままでは指定GPU captureから散乱の遮蔽差を検証できない。
- 許可パスには `RenderWorld.h/.cpp` と `RenderingCoordinator.h` が含まれない。パケットの公開経路を正しく追加するにはそれらの変更が必要になる。
- 初回ベースラインは指定4ターゲットbuild成功、契約CTest 3/3成功。GPU smokeは未実装引数 `--r3-scenario=shadowed-shafts` を拒否して exit 1。最終検証ログはまだ作成していない。

## 選択肢

1. **推奨: 設定APIを許可パスへ追加する。** `RenderWorld` と `RenderingCoordinator` に高さフォグ設定を追加し、GameThreadの設定値を次のFramePacketへコピーする。GPU fixtureからこのAPIを呼び、既定値と無効時の契約を保ちながら実シーンを検証できる。許可パスの拡張が必要。
2. **許可パス内でテスト専用の暗黙シグナルを使う。** カメラの予約値などから RenderThread 側でfogを強制する。公開APIを増やさずに済むが、検証用条件が描画処理へ漏れ、FramePacketの明示的スナップショット契約を弱めるため推奨しない。

推奨は選択肢1。許可パスの拡張が決まるまで `TASKS.md` の R3-P3 は `todo` のままとする。
